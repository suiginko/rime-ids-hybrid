# ==============================================================================
# ids_custom.txt - 部件模糊检字 用户自定义读音与禁用规则配置
# ==============================================================================
# 说明：
# 本文件用于自定义部件读音、添加俗称别名，或禁用/覆盖官方默认的读音映射。
# 修改后，在小狼毫右键菜单点击“重新部署”或“重启服务”即可立即生效。
#
# 语法支持以下 4 种操作：
# ------------------------------------------------------------------------------
# 1. 追加新增读音（格式：部件 读音1 读音2 ...）
#    例如：允许输入 biao 匹配 灬，输入 hu 匹配 氵
# 灬    biao
# 氵    hu
#
# 2. 精准删除某个官方读音（在读音前加减号 - ）
#    例如：官方默认 阝 可以通过 er 触发，如果你觉得容易误触，可以单独删除 阝 的 er 读音：
# 阝    -er
#    或者按拼音删除部件（效果相同）：
# -er   阝
#
# 3. 彻底禁用某个官方拼音音节（在拼音前加减号 - ，不跟部件）
#    例如：完全禁用拼音 er（输入 er 时不会命中任何部件）：
# -er
#
# 4. 覆盖重设读音（使用等号 = ）
#    清空该部件在官方表里的所有默认读音，仅保留这里指定的新读音：
# 阝    =fu yi
#
# 5. 禁用指定字符分区以减少硬件/内存负担（使用 -block 或 -区 或 -分区）
#    被禁用的分区字符在启动加载时将被彻底跳过，直接节省 40%~80% 内存开销：
#    支持的分区名称：基本、扩A、扩B、扩C、扩D、扩E、扩F、扩G、扩H、扩I、扩J、康熙部首、部首补充、兼容区、兼容补充
#    （也支持英文缩写如 exta, extb, kx, compat 等）
#    例如（取消注释即可生效）：
# -block 扩B 扩C 扩D 扩E 扩F 扩G 扩H 扩I 扩J 兼容补充
# ==============================================================================
