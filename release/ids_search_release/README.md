## 🚀 方式一：全自动一键安装（纯净独立方案）

1. 解压压缩包。
2. 鼠标右键点击 **`一键安装(管理员运行).bat`**，选择 **【以管理员身份运行】**。
3. 脚本会自动完成备份原版 `rime.dll`、核心替换、数据拷贝与部署。按提示完成后即刻生效！

---

## 🖐️ 方式二：极简手动安装（无脑拖拽 2 次，无需任何命令）

### 第 1 步：退出输入法
- 鼠标右键任务栏右下角小狼毫托盘图标 $\to$ 点击 **【退出】**。

### 第 2 步：复制文件
1. 打开 **`1.【小狼毫程序目录】`**，将其中的 `rime.dll` 复制替换到小狼毫安装目录（通常为 `C:\Program Files\Rime\weasel-0.17.4\`）。
2. 点击开始菜单启动小狼毫，右键托盘图标点击 **【用户文件夹】**（自动打开 `%APPDATA%\Rime`）；打开本包 **`2.【用户配置目录】`**，将里面的所有文件直接**全选复制粘贴进去**！

### 第 3 步：重新部署
- 鼠标右键小狼毫托盘图标 $\to$ 点击 **【重新部署】**。完成！

## ⌨️ 独立方案快速上手

- **开启检字**：按下快捷键 <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>Space</kbd>（或 <kbd>Ctrl</kbd> + <kbd>`</kbd> 选单）切换到【部件模糊检字】方案。
- **直接打字**：键入部件的全拼、小鹤双拼、自然码或汉字直接检索：
  - `mumu` $\to$ 检索出 `林`、`森`、`楚` 等
  - `kouhao` $\to$ 检索出 `𫩠`、`号` 等
  - `木木` $\to$ 支持部件汉字直接求交
- **切回原方案**：再次按下 <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>Space</kbd> 或 <kbd>Shift</kbd> + <kbd>Space</kbd> 秒速回切。
- **选字翻页习惯**：
  - 数字键 <kbd>1</kbd> ~ <kbd>9</kbd> 或 <kbd>空格</kbd> 直接选字；
  - 逗号 <kbd>,</kbd> 上一页，句号 <kbd>.</kbd> 下一页（同时支持 `-` / `=`，`[` / `]`）；
  - 分号 <kbd>;</kbd> 快速上屏第 2 候选。

## 🌟 万象拼音用户挂接（可选功能）

如果您平时主力使用【万象拼音】，并希望在打字过程中**直接敲大写 <kbd>I</kbd> 呼出检字**：
- 打开 **`可选：万象拼音挂接补丁(仅供参考)`** 目录下的 `wanxiang_patch_snippet.yaml`；
- 将那几行挂接代码**复制追加**到您既有的 `wanxiang_pro.custom.yaml` 的 `patch` 节点下；
- 右键【重新部署】即可。这样既能享受大写 `I` 前缀即时方案名提示与无缝检字，又能 100% 保护您的既有设置！
