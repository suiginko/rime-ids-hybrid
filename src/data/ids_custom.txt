# ids_custom.txt — 部件检字自定义读音 / 禁用分区示例
#
# 此文件是可选的。把文件名填入 ids_reverse/custom_file 后，重新部署即可生效。
#
# 支持以下写法：
#
# 1. 追加读音
#    部件 读音1 读音2 ...
#    灬   biao
#    氵   hu
#
# 2. 删除某个读音
#    阝   -er
#    -er  阝
#
# 3. 禁用某个拼音音节
#    -er
#
# 4. 覆盖重设读音
#    阝   =fu yi
#
# 5. 禁用字符分区
#    -block 扩B 扩C 扩D 扩E 扩F 扩G 扩H 扩I 扩J
#
# 默认不启用任何自定义规则，按需取消注释即可。

# 示例：给 灬 增加 biao 读音
# 灬   biao

# 示例：去掉 阝 的 yi 读音
# 阝   -yi
