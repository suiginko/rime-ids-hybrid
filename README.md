# Rime 全功能汉字部件检字套件

全量 10.4 万 Unicode 汉字（基本区 + 扩展 A~J）毫秒级部件检索，支持汉字、全拼与双拼混合检字。

---

## 快速使用方法

### 1. 混合检字（大写 `O` 引导，最推荐）
敲大写 **`O`** 引导，支持**汉字部件**与**拼音/双拼**混合检索：
- **汉字输入**：输入拼音后按空格选汉字部件，多个部件自动求交（如 `O木木` $\to$ 首选 `林`，`O沐木` $\to$ 首选 `淋`）；
- **减法功能**：支持在 `-` 减号后输入需要去掉的部件（如 `O佩-亻` $\to$ 首选 `𫥞`，`O春-日` $\to$ 首选 `𡗗`，`O森-木` $\to$ 首选 `林`）；
- **字母直出**：输入拼音或双拼后按回车，直接将字母编码作为部件检字（如 `Omu` 按回车 $\to$ 直接作为部件）；
- **双拼支持**：完美支持小鹤双拼、自然码等（如打 `kz` 自动识别为口，`ho` 自动识别为火）。

### 2. 纯字母检字（大写 `I` 引导）
敲大写 **`I`** 引导，连续键入各部件全拼或双拼：
- `Imumu` $\to$ 检索出 `林`、`森` 等
- `Ikouhao` $\to$ 检索出 `𫩠`、`号` 等

### 3. 一键上屏 IDS 拆解结构
候选框展示时，想直接输入该字的部件结构（如把 `鼯` 打成 `⿰鼠吾`）：
- **当前选中的字**：按 **`Ctrl + Enter`**（或 `Alt + Enter`）；
- **指定序号的字**：按 **`Ctrl + 1` ~ `5`**（例如按 `Ctrl + 3` 直接上屏第 3 个候选的 IDS 结构）。

### 4. 翻页与选字
- **选字**：数字键 `1` ~ `5` 或空格；
- **次选**：分号 `;` 快速选择第 2 候选；
- **翻页**：逗号 `,` 上一页，句号 `.` 下一页。

## 电脑端（Windows 小狼毫）安装方法

1. **退出小狼毫**：右键任务栏托盘图标 $\to$ 点击【退出】；
2. **替换 DLL**：将 `dist/bin/rime.dll` 复制覆盖到小狼毫安装目录（通常为 `C:\Program Files\Rime\weasel-0.17.4\`）；
3. **复制数据**：将 `data/ids_data.bin` 与 `schema/lua/` 下文件复制到用户配置目录 `%APPDATA%\Rime\`；
4. **重新部署**：右键托盘图标 $\to$ 点击【重新部署】即可。

---

## 手机端（Android 灵韵输入法 LyraIME）安装方法

- 灵韵输入法原生内置检字支持；
- 将 `ids_data.bin` 放入手机方案目录（`Documents/LyraIME/<方案包名>/`）及其 `build/` 目录；
- 在灵韵输入法设置中点击【重新部署】即可。
